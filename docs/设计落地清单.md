## 0. 使用方式

1. 按「批次 0 → 13」顺序执行，每批可独立验收与回退
2. 每批完成后在对应 `- [ ]` 打勾，并在批末填写验证结果

4. 回退方式：`git checkout <本批涉及文件>`

# CSS 语法自检（括号平衡）
cd web/styles
Get-ChildItem *.css | ForEach-Object {
  $c = Get-Content $_.FullName -Raw -Encoding UTF8
  $o = ([regex]::Matches($c,'\{')).Count
  $cl = ([regex]::Matches($c,'\}')).Count
  if ($o -ne $cl) { "MISMATCH $($_.Name) $o/$cl" }
}
