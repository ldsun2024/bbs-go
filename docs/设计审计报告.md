## 一、结论摘要

共发现 **17 项问题**：阻塞 4 项、重要 9 项、建议 4 项。

| 等级 | 数量 | 性质 |
|---|---|---|
| 🔴 阻塞 | 4 | 规范自身矛盾 / 文档与原型不一致 / token 三方命名冲突 |
| 🟠 重要 | 9 | 违反基线硬规则、跨文档数值冲突 |
| 🟡 建议 | 4 | token 未落地、命名不统一、缺注释 |

**一句话结论**：`design.css`（原型实际样式）是合规的，`design.md`（规格文字）不合规 —— 两者已经脱节，而规格文档才是开发依据，所以必须修 `design.md` 与规范。

## 二、阻塞级问题

### 🔴 B-1 规范自身矛盾：4.2「9 档唯一」vs 5.10「尺寸速查表」

`UI设计规范.md` 4.2 第 176 行明令：

> **禁止出现 9 / 9.5 / 10 / 10.5 / 11.5 / 12.5 / 13.5 / 14.5 / 17 / 18px** 这类中间值；需要时向上或向下归到最近一档

但同一份规范 5.10「尺寸速查表」（565-577 行）里直接使用了被禁止的值：

| 行号 | 元素 | 规范 5.10 写的字号 | 4.2 判定 |
|---|---|---|---|
| 568 | 列表项 | 16 / **13.5** / 12 | ❌ 13.5 |
| 571 | 表格内按钮 | **11.5** | ❌ 11.5 |
| 573 | 标签 | **11.5** | ❌ 11.5 |
| 574 | 分类 chip | **12.5** | ❌ 12.5 |
| 576 | 表头 | **11.5** | ❌ 11.5 |
| 577 | 表格行 | 13 | ✅ |

**这是所有 `design.md` 字号违规的源头**：A1/A2/A3/A4/B2/B5/C4 里的 12.5 / 13.5 / 14.5 / 11.5 / 10.5，全部可以追溯到 5.10 或 5.8。

### 🔴 B-3 token 三方命名不一致

同一批颜色在三处有三套名字：

| 语义 | `UI设计规范.md` 4.1 | `design/assets/design.css` | 已落地 `web/styles/globals.css` |
|---|---|---|---|
| 次要文字 | `--text-secondary` | `--muted` | `--muted-foreground` |
| 弱化文字 | `--text-muted` | **缺** | `--text-muted` ✅ |
| 赤陶强调 | `--accent-warm` | `--warm` | `--accent-warm` ✅ |
| 赤陶浅底 | `--accent-warm-soft` | `--warm-soft` | `--accent-warm-soft` ✅ |
| 灰蓝 | **规范无此 token** | `--slate` / `--slate-soft` | `--slate` ⚠️ |
| 信息色 | `--info` / `--info-soft` | **缺** | `--info` ✅ |

后果：`a5-content-types/design.md:41` 写 `--slate`、`b4` 写 `--brand`，开发照着文档写会遇到「变量不存在」；反之照 `design.css` 写，与规范又对不上。

### 🔴 B-4 `design.css` 缺三类关键 token

| 缺失 | 影响 |
|---|---|
| `--fs-*` 九档（无一个） | 字号没有 token 化，全部写死 px，这正是 B-1/B-2 反复出现的根因 |
| `--shadow-*`（无一个） | 但 `b5-notifications/design.md:46` 与 `c4-charts/design.md:46` 都引用了 `shadow-pop`，实际不存在 |
| `--info` / `--info-soft` | 规范 4.1 定义了，实现层没有 |

`design.css` 当前共 35 个 token，规范 4.1 定义 28 个颜色 token，实现只有 26 个（缺 info 两个），且命名不一致 2 个、自行新增 2 个。

### 🟠 I-7 表头底色冲突

### 🟠 I-9 空态形态冲突：线稿 vs 无图标

- 规范 5.7 第 538 行：空态 **左对齐（不用居中大图标）**，一行标题 + 一行说明 + 一个次按钮

5.7 明确说「不用居中大图标」，B3 却要求 120 线稿（列表左对齐时仍是大图标）。且 5.7 说「一个次按钮」，B3 要「主操作 + 次操作」两个。

## 四、建议级问题

### 🟡 S-1 字号未 token 化

`design.css` 的 9 档字号全部写死为 `font-size: 13px`，没有 `--fs-*` 变量。规范 4.2 定义了 9 个字号 token（`--fs-display` … `--fs-micro`），实现层一个都没建。

这是 B-1/B-2 反复出现的结构性原因：没有变量，取值就只能靠记忆。

### 🟡 S-2 间距出现 13 / 14 / 18

规范 4.3 允许：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（+ 卡片内边距 20）。

| 文件:行 | 值 | 应取 |
|---|---|---|
| `a1-typography/design.md:98` | `padding: 13px 18px` | `12px 16px` |
| `a4-composer/design.md:53` | 元信息行上下 14px | 16 |
| `a4-composer/design.md:56` | 正文区内边距 `18px 20px` | `16px 20px` |

### 🟡 S-3 C4 五色板有 2 色无 token

`c4-charts/design.md:31-35` 的 5 色中，`#6B7A47` 与 `#4A6274` 在规范 4.1 里找不到，需要补登记或改用现有 token。

### 🟡 S-4 README 与 5.10 不完全一致

`README.md:148` 写「表格行高 44，表头 38」，规范 5.10 第 576-577 行也是 38/44，但 5.6 第 531 行写 48。README 与 5.10 一致，5.6 是唯一的例外，应改 5.6。

## 五、根因分析

| 现象 | 根因 |
|---|---|
| 10 处字号违规 | 4.2 与 5.10 是两次不同时间维护的，5.10 沿用了 4.2 定稿前的旧值 |
| 文档与原型脱节 | 原型用 9 档（说明作者知道规则），`design.md` 抄了 5.10 的旧表，两者没做交叉校验 |
| token 三方命名冲突 | 规范 4.1 改名（`accent-warm`）后，`design.css` 没同步；`--slate` 是 A5 实现时才新增，未回写规范 |
| 3px 圆角屡禁不止 | 规范 4.4 自己承认「早期原型曾用 3px 做骨架与色条，统一改为 4」，但 A1/A5/C4 仍是旧稿 |
| `--shadow-pop` 引用不存在 | 规范 4.5 定义了浮层阴影，但 `design.css` 未实现 |
