# C1 · 分享卡片（OG 图）

> 所属：锦上添花 ｜ 工作量 M（约半天）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

现在分享链接到微信、Telegram、Twitter 时，只有标题和描述：

```html
<meta property="og:title" content="..." />
<meta property="og:description" content="..." />
<!-- 没有 og:image -->
```

结果是分享出去是一行干瘪的文字，点击率明显低于带图的卡片。

## 2. 目标

- 每类内容（话题 / 问答 / 文章）有对应的分享图
- 无封面图时也能生成一张排版卡片，不出现空白
- 生成成本低，不依赖设计每次手动做图

## 3. 方案

### 3.1 规格

| 项 | 值 |
|---|---|
| 尺寸 | 1200 × 630（1.91:1，微信/Twitter/Telegram 通用） |
| 安全区 | 四周 72px，内容不越界 |
| 底色 | `#FAF7F2` 暖白 + 细颗粒 |
| 主色块 | 底部 8px 墨绿横条 |
| 标题字号 | 44px，行高 1.35，最多 3 行 |
| 正文字号 | 22px，行高 1.6，最多 2 行 |
| Logo | 左上角 32px 方块 + 站名 24px 衬线 |
| 页脚 | 右下角作者头像 40px + 昵称 20px |

### 3.2 三种模板

| 类型 | 布局 | 特点 |
|---|---|---|
| **文章** | 左侧文字 62% + 右侧封面 38% | 有封面时用图，无双栏退化为居中排版 |
| **话题** | 全宽文字，标题 3 行 | 底部带分类 chip 与作者，无图也饱满 |
| **问答** | 标题 + 问题摘要 + 「悬赏」角标 | 赤陶色强调，区分于普通话题 |

### 3.3 生成方式（三选一）

| 方式 | 成本 | 说明 |
|---|---|---|
| **A. 前端截图** | 低 | 用 `@vercel/og` 或 `satori` 在 Node 端渲染 JSX 为 PNG，无需浏览器 |
| **B. 后端 Go 绘制** | 中 | `gg` 或 `canvas` 库直接画，字体需内嵌 |
| **C. 预生成 + 缓存** | 低 | 内容发布时生成一次存对象存储，之后直接引用 |

推荐 **A + C**：`satori` 渲染 → 存本地 `res/og/{type}-{id}.png` → 首次请求生成，之后命中缓存。失败时回退到站点默认图，不影响页面。

### 3.4 meta 标签

```html
<meta property="og:image" content="https://site/res/og/topic-1024.png" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta name="twitter:card" content="summary_large_image" />
```

## 4. 验收

- [ ] 三种模板在微信、Telegram 预览中显示正常
- [ ] 标题超长时截断为 3 行并加省略号，不溢出安全区
- [ ] 无封面图时排版版不出现空洞
- [ ] 生成失败时回退默认图，页面正常打开
