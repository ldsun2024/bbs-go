# A4 · 发布页 / 编辑器

> 所属：内容呈现 ｜ 工作量 M（约半天）｜ 依赖：A1（正文排版）、A3（表单规格）
> 原型：`prototype.html`

## 1. 问题

`web/styles/topic.css` 的 `.publish-form` 是发布页的全部样式来源：

| 现状 | 值 | 问题 |
|---|---|---|
| 表单容器 | `padding: 10px 18px 18px` | 上下 10px，标题与顶部边框几乎贴住 |
| 标题字段 | `font-size: 18px; font-weight: 500` | 与正文标题区分不出来，用户不知道"这行是标题" |
| 输入框圆角 | `3px` | 与卡片 10px 圆角冲突，边缘忽软忽硬 |
| 标题下边框 | `1px solid` + `padding-bottom: 10px` | 与容器边框、编辑器边框形成三条平行线 |
| 编辑器容器 | 无独立边界 | 工具栏、正文、标签区全糊在一起 |
| 底部操作 | `text-align: right` | 只有一个按钮，没有字数、草稿、可见性等辅助信息 |

发布是内容生产的入口，这版看起来像"能用的表单"，不像"写作的地方"。

## 2. 目标

- 让标题和正文有明确的视觉分工
- 工具栏、正文、元信息、操作区分成四个清晰的带
- 版心 760，写作时视线不被拉得太宽
- 与 A1 的正文规格保持一致（同一套字号与行高）

## 3. 方案

### 3.1 结构

```
┌─ 760 居中 ────────────────────────────┐
│ [标题输入 24px 衬线，仅底边线]         │
│ ─────────────────────────────────────  │
│ [分类 chip] [标签 chip] [+ 添加标签]   │
│ ─────────────────────────────────────  │
│ ┌ 编辑器 ───────────────────────────┐ │
│ │ 工具栏（浅底 40 高，下边线）       │ │
│ ├───────────────────────────────────┤ │
│ │ 正文区 260 高，18/20 内边距        │ │
│ └───────────────────────────────────┘ │
│ 已保存草稿 · 1,204 字      [预览][发布] │
└───────────────────────────────────────┘
```

### 3.2 规格

| 元素 | 规格 |
|---|---|
| 容器 | 760 宽，`--surface`，`radius 6`，内边距 24 |
| 标题输入 | 25px 衬线 600，无边框，仅 1px 底边线，focus 变 `--brand`，占位 400 字重 |
| 元信息行 | 上下 14px，分类 chip 26 高，`radius 4` |
| 编辑器容器 | 1px `--line`，`radius 6`，overflow hidden |
| 工具栏 | 高 40，`--bg-subtle` 底，下边线 1px，工具按钮 28×28，hover 变白底 |
| 正文区 | `min-height: 260`，内边距 `18px 20px`，14.5px / 1.9 |
| 底部 | 左侧 12px 提示（草稿状态 + 字数），右侧「预览」描边 + 「发布」主按钮 |
| 圆角 | 全链路 6px，不再出现 3px |

### 3.3 交互规则

- 标题为空时「发布」禁用，不弹错误
- 正文 focus 时工具栏保持可见（不浮动）
- 分类 chip 单选，标签 chip 多选，选中态 `--brand` 实底
- 草稿状态文字在「未保存 / 保存中 / 已保存」三态间切换，不弹 Toast

## 4. 验收

- [ ] 标题与正文一眼能分清主次
- [ ] 工具栏、正文区之间有明确分隔
- [ ] 编辑器内不出现 3px 圆角
- [ ] 底部操作区同时可见字数与草稿状态
- [ ] 宽度 < 860 时容器占满，内边距降到 16
