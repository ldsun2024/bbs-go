做题时总是要在草稿纸上画一下才敢确定，考试来不及。老师提过「a 正开口向上」，但遇到顶点式和交点式就乱了。

我的做法是先把式子化成一般式，看 a 的符号，再求对称轴。问题是化简本身要花时间，而且容易算错。

  • y = 2(x − 1)² − 3，能直接看出开口向上吗
  • y = −0.5(x + 2)(x − 4)，a 是 −0.5 还是别的值

四个功能带 标题 / 元信息 / 编辑器 / 操作

1. 标题带
24px 衬线，无边框只留 1px 底边线，focus 变墨绿。占位文字 400 字重、`--muted` 色，与已输入内容形成对比。
2. 元信息带
分类 chip 单选 + 标签 chip 多选，上下 14px。虚线边框的「+ 标签」明确表达"可添加"。
3. 编辑器
工具栏 40 高、浅底、下边线，与正文区彻底分开。正文 260 高起，行高 1.9 与 A1 一致。
4. 操作带
左侧常驻草稿状态与字数，右侧预览 + 发布。状态用文字而非 Toast，写作时不被打断。

对比现状

.publish-form { padding: 10px 18px 18px } —— 标题几乎贴住上边框
.form-title-name { font-size: 18px; font-weight: 500 } —— 与正文标题无法区分
.field input { border-radius: 3px } —— 卡片 10px 圆角里嵌着 3px 锐角
标题下边框 + 容器边框 + 编辑器边框 = 三条平行线，页面被切碎
底部只有 text-align: right 的一个按钮，没有字数与草稿反馈
