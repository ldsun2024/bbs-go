# B3 · 空态与错误页

> 所属：细节打磨 ｜ 工作量 S（约 2 小时）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

项目里存在两套互不相干的"没有内容"表现：

| 位置 | 现状 | 问题 |
|---|---|---|
| `EmptyState`（列表空） | 居中图标 + 一行文字 | 没有下一步动作，用户只能离开 |
| `ErrorPage`（404 / 500） | 独立组件，样式与空态不同 | 同一个站里出现两种"空"的视觉语言 |
| 搜索无结果 | 直接显示空列表 | 不提示"换个关键词"，用户以为页面坏了 |
| 后台表格空 | 显示一行空白 | 分不清"没数据"还是"没加载完" |

四种场景各写各的，用户看到的是四种不同的"空"。

## 2. 目标

- 四种场景共用一套结构与尺寸
- 每个空态都给出**一个**明确的下一步动作
- 与站点排版风格一致（衬线标题 + 无衬线说明）

## 3. 方案

### 3.1 统一结构

```
[ 120px 单色线稿 ]
标题（20px 衬线 600）
说明（13px，最多两行，--text-2）
[ 主操作 ] [ 次操作 ]
```

### 3.2 两种对齐

| 场景 | 对齐 | 理由 |
|---|---|---|
| 列表空 / 后台表格空 | **左对齐** | 与列表内容左边界对齐，不像"报错"，更像"提示" |
| 404 / 500 / 权限不足 | **居中** | 整页级中断，需要一个明确的视觉中心 |

### 3.3 四套文案与动作

| 场景 | 标题 | 说明 | 主操作 |
|---|---|---|---|
| 列表空 | 这里还没有内容 | 成为第一个发布的人，一条清晰的开场会带来更多回复 | 发布第一条 |
| 搜索无结果 | 没有找到相关内容 | 试试更短的关键词，或换个说法 | 清空筛选 |
| 404 | 页面不存在 | 链接可能已失效，或者内容已被作者删除 | 回到首页 |
| 500 | 服务出了点问题 | 已经记录这次异常，稍后重试通常能恢复 | 重新加载 |

### 3.4 线稿规范

- 尺寸 120×120，居中
- 只用一个颜色：`--line-strong`（浅灰褐）
- 线宽 2px，圆角端点
- 不加阴影、不加渐变、不加彩色
- 四种场景用不同图形：空盒子 / 放大镜 / 断开的路径 / 断裂的圆

## 4. 验收

- [ ] 四种空态在视觉上属于同一族
- [ ] 每个空态都有可点的下一步
- [ ] 线稿在暗色模式下仍然可见（不用纯黑描边）
- [ ] 后台表格空态不显示成"一行空白"
