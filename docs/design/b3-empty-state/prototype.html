空态与错误页

一套结构、两种对齐、四种文案。线稿只用 --line-strong 单色。
B3

四种场景 列表空 / 搜索无结果 / 404 / 500

列表空 · 左对齐

这里还没有内容

成为第一个发布的人，一条清晰的开场会带来更多回复。

搜索无结果 · 左对齐

没有找到相关内容

试试更短的关键词，或换个说法。也可以直接在问答区提问。

404 · 居中

页面不存在

链接可能已失效，或者内容已被作者删除。

500 · 居中

服务出了点问题

已经记录这次异常，稍后重试通常能恢复。

规格

结构
线稿 120×120 → 间距 16 → 标题 18px 衬线 600 → 间距 8 → 说明 13.5px（最多两行）→ 间距 18 → 主操作 + 次操作
线稿只用 --line-strong，线宽 2，圆角端点，不加阴影与渐变
为什么两种对齐
列表空态左对齐：与内容左边界对齐，读起来像"提示"而不是"报错"，不会打断浏览节奏。
404 / 500 居中：整页级中断，需要一个明确的视觉中心告诉用户"到这里为止了"。

后台表格空态也用左对齐，但高度压到 200，避免整页只有一块空白。
