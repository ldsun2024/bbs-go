# B4 · 图标与徽章一致性

> 所属：细节打磨 ｜ 工作量 S（约 2 小时）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

图标体系目前是"三套并存"：

| 来源 | 用法 | 问题 |
|---|---|---|
| lucide-react | 导航、按钮、操作 | 主流，但尺寸从 14 到 24 混用 |
| emoji | 分类 logo、部分空态 | 与线性图标风格冲突，跨平台渲染不一致 |
| 自绘 SVG | `/res/images/badges/` 的 9 个徽章 | 画布尺寸、描边粗细、配色都不统一 |

具体表现：

- 同一行里出现「线性图标 + 彩色 emoji + 图片 logo」三种画风
- emoji 在 Windows 是彩色、在部分 Linux 是黑白，同一个站点在不同设备上差很多
- 9 个徽章有的 32px 画布、有的 48px，摆在一起高低不齐
- 分类没有 logo 时直接空白，没有兜底

## 2. 目标

- 全站图标只保留**一种画风**（线性、单色）
- 分类有稳定的兜底图标，不依赖运营上传
- 徽章统一画布与描边，任意组合排列都对齐

## 3. 方案

### 3.1 图标规范

| 项 | 规格 |
|---|---|
| 图标库 | 只用 `lucide-react`，不引入第二个 |
| 画布 | 24×24，`viewBox="0 0 24 24"` |
| 描边 | 1.5px（`stroke-width: 1.5`），圆角端点 |
| 尺寸档 | 14（内联文字）/ 16（按钮）/ 20（导航）/ 24（页面级） |
| 颜色 | `currentColor`，不写死颜色 |
| 禁止 | emoji 作为功能图标；同一语义用两个不同图标 |

### 3.2 分类兜底图标映射

分类没有上传 logo 时，按名称关键词映射到 lucide 图标：

| 关键词 | 图标 |
|---|---|
| 数学 / 函数 | `Sigma` |
| 语文 / 阅读 / 写作 | `BookOpen` |
| 英语 / 语言 | `Languages` |
| 科学 / 实验 / 物理 / 化学 | `FlaskConical` |
| 问答 / 求助 | `MessageCircleQuestion` |
| 公告 / 通知 | `Megaphone` |
| 活动 / 运动 | `Activity` |
| 其他 | `Hash` |

映射表放在前端常量里，不改后端；运营上传了 logo 就优先用图片。

### 3.3 徽章规范

| 项 | 规格 |
|---|---|
| 画布 | 48×48（小尺寸显示 32、24 时等比缩放） |
| 描边 | 2px，圆角端点 |
| 配色 | 主体 `--brand`，辅助 `--warm`，底色 `--brand-soft` |
| 形状 | 统一圆形外框 + 内部图形 |
| 命名 | `badge-{语义}.svg` |

### 3.4 替换顺序

1. 先把 emoji 出现的位置列出来（分类 logo、空态、引导页）
2. 分类改为「有图用图，无图用映射图标」
3. 徽章按新画布重绘（或先统一缩放到 48 画布，不改图形）
4. 最后统一 lucide 尺寸为 14/16/20/24 四档

## 4. 验收

- [ ] 页面上不再出现彩色 emoji 作为功能图标
- [ ] 分类没有 logo 时显示单色图标而不是空白
- [ ] 9 个徽章在同一行排列时高度一致、描边粗细一致
- [ ] 所有图标颜色跟随父级（暗色模式自动适配）
