# A3 · 登录 / 注册

> 所属：内容呈现 ｜ 工作量 S（约 2 小时）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

`web/styles/auth.css` 的登录卡片几乎没有间距设计：

| 现状 | 问题 |
|---|---|
| `.signin-card { padding: 0.25rem 0.75rem }` | 4px / 12px 的内边距，标题和输入框直接贴边 |
| `.login-title` 带 `border-bottom` | 标题下一条线，与卡片边框形成双线 |
| 第三方登录按钮与主按钮同样式同尺寸 | 主次不分，用户不知道该点哪个 |
| 单位混用 | 同在 auth.css 里出现 `0.25rem`、`1rem`、`1.5rem`、`16px` 四种写法 |
| 无左侧说明区 | 整页只有一个窄表单，首屏空旷 |

登录是用户接触产品的第一屏，这版显得"能用但没人管"。

## 2. 目标

- 首屏有信息量，不是一张飘在中间的白卡
- 主操作（登录/注册）绝对突出，第三方登录降级
- 内边距成体系，最小 32
- 移动端单栏，左栏隐藏

## 3. 方案

### 3.1 结构

```
┌──────────────────────┬──────────────────┐
│ 左栏（品牌说明）      │ 右栏 420px（表单）│
│                      │                  │
│ 「把问题问清楚，      │ [登录|注册] 切换  │
│   把答案留下来」      │ 账号             │
│                      │ 密码             │
│ · 话题 / 文章 / 问答  │ [ 登 录 ] 全宽   │
│ · 支持第三方登录      │ ─── 或 ───       │
│                      │ [微信] [GitHub]  │
│                      │ 忘记密码 / 注册   │
└──────────────────────┴──────────────────┘
```

左栏 480~520px 自适应，右栏固定 420px。整体最大 900，圆角 8，1px 边框。

### 3.2 规格

| 元素 | 规格 |
|---|---|
| 外框 | 900 宽，`radius-lg`，1px `--line`，overflow hidden |
| 左栏 | 底 `--bg-subtle` + 墨绿径向渐变（12%），内边距 40 |
| 左栏标题 | 25px 衬线 600，行高 1.45 |
| 左栏说明 | 13px / 1.85，`--text-2` |
| 右栏 | `--surface` 底，内边距 36 / 32 |
| 分段切换 | 底 `--bg-subtle`，容器内边距 3，选中项白底 + 微阴影 |
| 输入框 | 高 40，`radius 6`，focus 有 3px 光晕 |
| 主按钮 | 全宽 40，`--brand` 实底 |
| 分割线 | 两侧 1px 线 + 中间 11.5px 文字「或」 |
| 第三方按钮 | 等高 38，均分，描边样式（`--surface` + 1px 边框） |
| 底部链接 | 12px，居中，`--muted`，链接 hover 变 `--brand` |

### 3.3 与现有规则的关系

- 类名沿用 `.signin-card` / `.login-title`，只改内部规格
- Vue/React 结构不变，仅调整 CSS 与一处容器包裹（加左栏）
- 若不想动 DOM，最小版：只改 `padding`、去掉 `border-bottom`、第三方按钮降级为描边

## 4. 验收

- [ ] 输入框与卡片边缘距离 ≥ 32
- [ ] 主按钮视觉权重明显高于第三方按钮
- [ ] 页面上不再出现「双线」（标题下划线 + 卡片边框）
- [ ] 宽度 < 900 时左栏隐藏，表单占满
