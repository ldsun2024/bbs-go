二次函数图像与性质

二次函数是初中数学的重点，也是高中函数思想的基础。它的图像是一条抛物线，形状完全由解析式中的三个系数决定。理解这三者的作用，比记住结论更重要。

一般式写作 y = ax² + bx + c，其中 a 决定开口方向与开口大小，b 与 a 共同决定对称轴位置，c 是与 y 轴交点的纵坐标。

判断对称轴位置时，容易只看 b 的符号而忽略 a，导致「左同右异」用反。

顶点式 y = a(x − h)² + k 可以直接读出顶点坐标 (h, k)，在求最值问题时最方便。交点式则适合已知与 x 轴两个交点的情况。

二次函数图像与性质

二次函数是初中数学的重点，也是高中函数思想的基础。它的图像是一条抛物线，形状完全由解析式中的三个系数决定。理解这三者的作用，比记住结论更重要。

一般式写作 y = ax² + bx + c，其中 a 决定开口方向与开口大小，b 与 a 共同决定对称轴位置，c 是与 y 轴交点的纵坐标。

三种表达式的适用场景

  • 一般式：已知三点求解析式
  • 顶点式：已知顶点与另一点
  • 交点式：已知与 x 轴的两个交点
判断对称轴位置时，容易只看 b 的符号而忽略 a，导致「左同右异」用反。记法：a、b 同号则轴在 y 轴左侧。

代码示例

// 求顶点坐标
function vertex(a, b, c) {
  const h = -b / (2 * a)
  const k = (4 * a * c - b * b) / (4 * a)
  return { h, k }
}

参数对照

参数 作用 判断方法
a 开口方向与大小 a > 0 向上，|a| 越大越窄
b 与 a 共同定对称轴 左同右异
c 与 y 轴交点 令 x = 0 求 y

以上三节覆盖了二次函数在初中阶段的全部考点。
