# A2 · 个人主页

> 所属：内容呈现 ｜ 工作量 M（约半天）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

`web/styles/user.css` 的 `.profile` 是一组硬编码像素的拼装：

| 现状 | 值 | 问题 |
|---|---|---|
| 头图高度 | `height: 220px` | 固定高，宽屏下变成一条极扁的横带，窄屏又过高 |
| 头像定位 | `position:absolute; top:100px` | 与头图高度强耦合，改头图高度头像就错位 |
| 信息区 | `margin-top:150px; padding-left:120px` | 又一处魔法数字，且左侧 120px 是为头像留白，头像换尺寸就崩 |
| 信息区背景 | `linear-gradient(90deg, #ffffff, rgba(255,255,255,.5), #dce9f2 00)` | **硬编码白色**，暗色模式下出现一条白色横带 |
| 统计数据 | 竖排在 `.metas` 里 | 关注/粉丝/帖子三个数字挤成一列，看不出主次 |

三处魔法数字（220 / 100 / 150 / 120）互相依赖，任何一处调整都会连带错位。

## 2. 目标

- 头图与头像用比例 + 负边距，不再依赖固定高度
- 信息区不写死左内边距
- 暗色模式不出现白色块
- 统计数字横排，视觉上有主次

## 3. 方案

### 3.1 结构

```
┌───────────────────────────────────────┐
│  头图  aspect-ratio: 16/5             │
│                                       │
└──────────────────┬────────────────────┘
                   │ ← 头像 88px，margin-top: -44px 压在交界处
┌──────────────────┴────────────────────┐
│ 昵称 + 等级徽标            [编辑资料] │
│ 加入时间 · 所在地 · 关注 32             │
│ 简介两行                               │
│ ─────────────────────────────────────  │
│ 帖子 128 │ 关注 32 │ 粉丝 96 │ 获赞 1.2k │
└───────────────────────────────────────┘
```

### 3.2 规格

| 元素 | 规格 |
|---|---|
| 头图 | `aspect-ratio: 16/5`，最大高 240px，圆角 6px 6px 0 0 |
| 头图底色 | 墨绿径向渐变（`--brand` 系），**不出现白色** |
| 头像 | 88px，`margin-top: -44px`，4px 白色描边（用 `--surface`） |
| 信息区 | `padding: 12px 28px 24px`，`--surface` 底，下圆角 6px |
| 昵称 | 25px 衬线 600（h1 档） |
| 元信息 | 12.5px，`·` 分隔，`--muted` |
| 简介 | 13.5px / 1.8，最大宽 560px |
| 统计条 | 4 等分横排，数字 20px 等宽，标签 12px，项间 1px 竖分隔线 |
| 内容区 | 下方接 tab（帖子 / 文章 / 收藏 / 赞过）+ 列表 |

### 3.3 暗色处理

头图渐变改用 `--brand` 与 `--brand-soft`，信息区用 `--surface`，不再出现任何硬编码白色。描边色从 `#fff` 改为 `var(--surface)`。

## 4. 实现要点

```css
.profile-cover {
  aspect-ratio: 16 / 5;
  max-height: 240px;
  border-radius: 6px 6px 0 0;
  background:
    radial-gradient(120% 140% at 15% 0%, rgba(20,102,90,.35), transparent 55%),
    linear-gradient(135deg, #234c46, #3c7367);
}

.profile-avatar {
  width: 88px;
  height: 88px;
  margin-top: -44px;
  border: 4px solid var(--surface);
  border-radius: 999px;
}
/* 删除 .profile 的 height / top / margin-top / padding-left 四处魔法数字 */
```

- [ ] 暗色模式下无白色横带
- [ ] 头像与头图交界处无错位
- [ ] 统计四个数字在同一基线上
