新旧对照

现状的四处魔法数字
.profile { height: 220px }
.profile-avatar { top: 100px }
.profile-info { margin-top: 150px }
.profile-info { padding-left: 120px }

四者互相依赖：改头图高度 → 头像错位 → 留白不够 → 内容被头像压住。

另外信息区背景写死了 #ffffff，暗色模式下露出一条白色横带。
新方案
头图 aspect-ratio: 16/5，不再固定高度
头像 margin-top: -44px，靠负边距压交界
信息区 padding: 12px 28px 24px，无魔法数字
统计四等分横排，项间 1px 竖线

头图渐变改用 --brand 系，信息区用 --surface，暗色下不出现白色块。

头像描边从 #fff 改为 var(--surface)，跟随主题。
