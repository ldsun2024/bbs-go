# B2 · 后台信息密度

> 所属：细节打磨 ｜ 工作量 M（约半天）｜ 依赖：B3（空态）
> 原型：`prototype.html`

## 1. 问题

后台表格页（`/dashboard/*`）用的是配置式 `DashboardDataPage`，视觉上缺少三样东西：

| # | 问题 | 影响 |
|---|---|---|
| 1 | 筛选栏与表格之间没有明确分隔 | 用户分不清"哪行是筛选、哪行是表头" |
| 2 | 表头不固定 | 列表滚到第 30 行，列名已经看不见，只能靠记忆猜 |
| 3 | 没有行选择与批量操作 | 删除 10 条要重复 10 次点击 |
| 4 | 行高不统一 | 标题长的行撑高，视觉上像"楼梯" |
| 5 | 分页样式与前台不一致 | 方形、圆形、文字链接混着出现 |
| 6 | 数字列左对齐 | 浏览量、评论数位数不同时无法纵向比较 |

## 2. 目标

- 筛选 / 表头 / 数据三层分离清晰
- 长列表滚动时始终能看到列名
- 支持多选后的批量操作
- 行高统一 44，数字右对齐

## 3. 方案

### 3.1 三段结构

```
┌ 页面头：标题 + 右侧主操作 ──────────────┐
├ 筛选栏 48 高，底部 1px 分隔 ───────────┤
│ [关键词____] [分类▾] [状态▾]  [重置][查询] │
├ 批量条（选中时出现，44 高，浅色底）────┤
│ 已选 3 项   [批量删除] [导出]           │
├ 表格 ─────────────────────────────────┤
│ ☐ ID   标题            分类  状态  浏览  操作│ ← sticky
│ ☐ 1024 二次函数图像...  数学  正常  3,842 编辑│
│ ☐ 1025 重仓持有...      心理  待审  2,540 编辑│
├ 分页（靠右，32px 方形）───────────────┤
└───────────────────────────────────────┘
```

### 3.2 规格

| 元素 | 规格 |
|---|---|
| 筛选栏 | 高 48，内边距 0 20，底部 1px `--line`，控件间距 10 |
| 筛选控件 | 高 32，`radius 4`，输入框宽 200，下拉宽 120 |
| 表头 | `position: sticky; top: 0`，高 38，`--bg-subtle` 底，11.5px，`--muted` |
| 复选框列 | 宽 40，居中 |
| 数据行 | 高 44（`height` 而非 `min-height`），标题列单行省略 |
| 数字列 | 右对齐 + `tabular-nums` |
| 操作列 | 固定右侧，文字按钮 26 高 |
| 批量条 | 选中 ≥1 时出现在筛选栏下方，44 高，`--brand-soft` 底 |
| 分页 | 右对齐，32×32，当前页 `--brand` 实底 |
| 空态 | 表格内居中，高 200 |

### 3.3 关键实现

```css
.tb thead th {
  position: sticky;
  top: 0;
  z-index: 10;
  background: var(--bg-subtle);
}
.tb td { height: 44px; }         /* 固定行高，避免长短不一 */
.tb .num { text-align: right; font-variant-numeric: tabular-nums; }
```

sticky 表头需要表格外层有固定高度或页面滚动容器，否则 `top: 0` 相对视口不生效。

## 4. 验收

- [ ] 滚动 50 行后仍能看到列名
- [ ] 所有数据行高度一致
- [ ] 选中行后批量操作条出现，取消选择后消失
- [ ] 数字列纵向对齐
- [ ] 分页样式与前台列表页一致
