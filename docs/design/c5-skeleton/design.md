# C5 · 骨架屏统一

> 所属：锦上添花 ｜ 工作量 S（约 1.5 小时）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

加载态目前有三种并存：

| 位置 | 现有表现 |
|---|---|
| 列表首次加载 | 空白，直到数据返回 |
| 部分页面 | 居中转圈（`Loader2` + `animate-spin`） |
| 详情页 | 文字「加载中...」占位 |
| 后台表格 | 空表格 + 无提示 |
| 表单提交 | 全屏半透明遮罩 + 转圈（这个是合理的） |

同一个站点，五种 loading 语言。用户不知道"是没数据还是在加载"。

## 2. 目标

- 首屏加载一律用骨架，不用转圈
- 骨架形状与真实内容对齐，数据到达时不跳动
- 提交类操作保留遮罩（因为需要阻止重复点击）

## 3. 方案

### 3.1 三类骨架

| 场景 | 形状 |
|---|---|
| **列表页** | 3~5 条：左侧日期块 40×40 + 右侧标题 92% / 摘要 78% / 元信息 40% |
| **详情页** | 标题 92%（高 28）+ 元信息 40% + 正文 6 行（100/95/88/100/72/45%） |
| **后台表格** | 表头 1 行 + 数据 6 行，每行 5 列等宽块 |

### 3.2 规格

| 项 | 值 |
|---|---|
| 块高度 | 标题 16、正文 12、元信息 10、块 40×40 |
| 圆角 | 4（`--radius-sm`） |
| 底色 | `--bg-subtle` |
| 动画 | 透明度 0.65 → 1 呼吸，周期 1.4s，`ease-in-out` |
| 间距 | 块间 8，条目间 24 |
| 数量 | 列表 4 条、正文 6 行、表格 6 行（不超过首屏） |
| 宽度递减 | 100% → 95% → 88% → 72% → 45%，模拟段落自然长度 |

### 3.3 与真实内容的对齐

骨架必须和真实内容**同样的高度与列宽**，否则数据到达时页面跳动（CLS）。做法：

- 列表项骨架沿用 `.topic-item` 的 `grid-template-columns` 与 `padding`
- 表格骨架沿用真实 `th` 宽度
- 正文骨架沿用 `.prose` 的 `line-height`

### 3.4 禁用场景

- ❌ 全屏转圈（除表单提交）
- ❌ 文字「加载中...」
- ❌ 骨架持续超过 3 秒仍不消失（应转为超时提示）

## 4. 验收

- [ ] 首屏加载看不到空白与转圈
- [ ] 数据到达后页面不跳动（高度一致）
- [ ] 暗色模式下骨架可见但不刺眼
- [ ] 超过 3 秒显示「加载较慢，请检查网络」并保留重试按钮
