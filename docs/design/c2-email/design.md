# C2 · 邮件模板

> 所属：锦上添花 ｜ 工作量 S（约 2 小时）｜ 依赖：无
> 原型：`prototype.html`

## 1. 问题

项目会发三类邮件（`t_email_log` 有记录）：邮箱验证、密码重置、回复通知。当前内容基本是纯文本或浏览器默认 HTML：

- 没有站点标识，用户分不清是哪个站发的
- 链接直接裸露成 URL，手机上是一长串不可点的文本（部分客户端）
- 没有页脚退订/联系方式，长这样容易被判为垃圾邮件
- 没有预处理器（preheader），收件箱列表里只显示正文前几个字

## 2. 目标

- 一眼能认出是本站发的
- 手机上（375px）按钮可点、不横向滚动
- 兼容 Outlook / Gmail / 微信内置邮箱
- 三封模板共用一套骨架，只换内容区

## 3. 方案

### 3.1 骨架

```
┌ 600px 居中 ─────────────────────┐
│ 顶部 24px 留白                   │
│ [logo 28] 禅龙诀                 │  ← 品牌行
│ ──────────────────────────────── │
│ 邮件标题（22px 衬线）             │
│ 正文段落（15px / 1.8）            │
│ [ 主按钮 全宽 ]                  │
│ 备用链接（12px，可复制）          │
│ ──────────────────────────────── │
│ 页脚：发件原因 · 联系邮箱 · 地址  │
└─────────────────────────────────┘
```

### 3.2 技术约束（邮件与网页不同）

| 约束 | 做法 |
|---|---|
| 不支持 `<style>` 里的复杂选择器 | **全部内联样式**，或 `<style>` + 内联双份 |
| 不支持 flex / grid | 用 `<table role="presentation">` 布局 |
| 按钮不是 `<button>` | 用 `<a>` + `padding` + `background`，外层 table 兼容 Outlook |
| 图片默认被拦截 | 品牌用文字 + CSS 方块，不依赖图片加载 |
| 宽度 | 600px 固定，外层 `width:100%` 兜底 |

### 3.3 三封内容

| 模板 | 标题 | 主按钮 | 有效期 |
|---|---|---|---|
| 邮箱验证 | 验证你的邮箱地址 | 验证邮箱 | 24 小时 |
| 密码重置 | 重置你的登录密码 | 设置新密码 | 1 小时 |
| 回复通知 | 有人回复了你 | 查看回复 | — |

密码重置邮件需额外提示「若非本人操作请忽略，账号不会受影响」。

### 3.4 暗色模式

主流客户端会自动反色，但会破坏对比度。处理方式：

```html
<meta name="color-scheme" content="light dark" />
<meta name="supported-color-schemes" content="light dark" />
```

并在 `<style>` 里加 `@media (prefers-color-scheme: dark)`，只调整背景与文字，不换品牌色。

## 4. 验收

- [ ] 375px 宽度下不出现横向滚动
- [ ] 按钮在 Outlook 桌面版可见（table 包裹）
- [ ] 图片未加载时版式不塌
- [ ] 收件箱列表能看到 preheader 摘要
- [ ] 页脚有「为什么收到这封邮件」与退订入口
