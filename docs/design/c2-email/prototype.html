邮件专属约束 和网页不一样

不能用网页的做法
邮箱客户端不支持 flex / grid，必须用 <table role="presentation">
<style> 常被剥离，关键样式要内联
图片默认被拦截，品牌不能只靠 logo 图
按钮不能用 <button>，要用 <a> + padding + 背景
部分客户端会强制反色，需要 color-scheme 声明
统一规格
宽 600，四周 28 / 32 内边距
标题 21px 衬线，正文 14px / 1.8
主按钮 44 高全宽，圆角 6，墨绿实底
备用链接 11.5px 可复制
页脚 11px：收件原因 + 联系邮箱 + 退订
preheader 隐藏摘要，决定收件箱列表显示内容
