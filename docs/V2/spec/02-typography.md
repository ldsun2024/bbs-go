# 02 · Typography

> 方向：**A · 瑞士网格**
> 版本：v1.0 ｜ 2026-10-20
> 前置：`01-tokens.md`

---

## 一、为什么 A 不用衬线

B 用衬线（书卷、夜间长读），C 用极粗无衬线（报纸头版）。A 的选择是：

**全部无衬线，靠字号、字重、字距、留白建立层级，不靠字体族切换。**

这与国际主义平面设计一致：Helvetica 一类的中性无衬线，把「阅读」还原成纯粹的信息传递，不制造情绪。

A 唯一允许的「字体对比」是**中英文比例**与**等宽数字**，不是衬线/无衬线的对比。

## 二、字体栈

```css
/* 正文 / UI / 标题，共用一套 */
--a-font: "Helvetica Neue", "Helvetica", "Inter",
          "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
          sans-serif;

/* 数字 / 编号 / 时间 / 统计 */
--a-mono: "SFMono-Regular", "JetBrains Mono", "Roboto Mono",
          Consolas, "PingFang SC", monospace;
```

### 为什么这样排

| 位置 | 字体 | 理由 |
|---|---|---|
| 1-3 位 | Helvetica Neue / Helvetica / Inter | 西文与数字的首选，字腔紧、中性 |
| 4-6 位 | PingFang SC / 冬青黑 / 微软雅黑 | 中文回退链，Win 与 macOS 都有解 |
| 末尾 | sans-serif | 兜底 |

**不引入网络字体**。理由：中文 Web 字体动辄 2-5 MB，原型要离线可开，生产环境也应以系统字体为主。

**不用 `system-ui`**：它会让 Windows 落到 Segoe UI + 雅黑、macOS 落到 SF + 苹方，两端字距差异明显，A 这种紧字距排版会失控。

## 三、字号阶（9 档）

| Token | 字号 | 行高 | 字重 | 字距 | 典型用途 |
|---|---|---|---|---|---|
| `--a-fs-display` | 56 | 1.02 | 700 | -0.035em | 首页主标题（一行不超过 14 字） |
| `--a-fs-h1` | 40 | 1.15 | 700 | -0.02em | 详情页标题、页面主标题 |
| `--a-fs-h2` | 28 | 1.25 | 700 | -0.015em | 区块标题、统计数字 |
| `--a-fs-h3` | 22 | 1.35 | 600 | -0.01em | 列表项标题 |
| `--a-fs-h4` | 18 | 1.5 | 600 | 0 | 小标题、侧栏标题 |
| `--a-fs-body` | 16 | 1.7 | 400 | 0 | 正文、摘要 |
| `--a-fs-ui` | 14 | 1.6 | 400 | 0 | 按钮、导航、表单、次要正文 |
| `--a-fs-sm` | 12 | 1.5 | 400 | 0 | 元信息、表格内容、时间 |
| `--a-fs-micro` | 11 | 1.4 | 600 | 0.14em | 大写 kicker、栏目标记、角标 |

### 行高的分配逻辑

- **越大越紧**：56px 行高 1.02（几乎贴着），40px 1.15，28px 1.25
- **越小越松**：16px 1.7，12px 1.5
- 原因：大标题行数少、需要「块状」的紧凑感；小字行数多、需要呼吸。

### 字重的分配

只用 **400 / 600 / 700** 三档。

- 400：正文、说明、次要信息
- 600：列表标题、小标题、按钮文字
- 700：页面标题、统计数字、Logo

**禁止 800 / 900**。中文在 800 以上会糊成一团（Windows 渲染尤其明显）。C 方向用 800 是因为它整页都是大标题，A 不是。

## 四、字距规则

| 场景 | 字距 | 说明 |
|---|---|---|
| 56px 主标题 | `-0.035em` | 大字号天然显松，必须收紧 |
| 40px 标题 | `-0.02em` | 同上 |
| 28 / 22px | `-0.015em` / `-0.01em` | 轻微收紧 |
| 18px 及以下 | `0` | 中文字距本来就紧，再收会粘 |
| 11px 大写标记 | `0.14em` | **大写字母必须放字距**，否则挤在一起 |
| 数字（等宽） | `0.02em` | 等宽数字天然对齐，略放一点 |

**禁止给中文正文加 `letter-spacing`**。中文是方块字，字距放大只会显得松散，不显高级。

## 五、中文排版细则

### 5.1 行宽

| 内容 | 最大宽度 | 约合字数（16px） |
|---|---|---|
| 主标题（56px） | `14em` | 14 字/行 |
| 正文 / 摘要 | `38em` | 38 字/行 |
| 侧栏文字 | `100%`（约 280px） | 17 字/行 |

超过 38 字/行，眼睛从行尾回到行首会串行。所以详情页版心锁 760px。

### 5.2 段间距

- 段落之间：`1.15em`（约 18px）
- 段落内部：行高 1.7
- **段间距必须大于行间距**，否则看不出分段

### 5.3 标点

| 类型 | 规则 |
|---|---|
| 中文标点 | 用全角：`，。？！：；「」（）` |
| 西文标点 | 用半角：`, . ? ! : ;` 后面跟一个空格 |
| 中英混排 | **不加空格**，直接连写：「支持 Markdown 语法」 |
| 数字与中文 | **加一个细空格**（`&thinsp;` 或 `margin-left:2px`）：「共 1,284 条」 |
| 引号 | 中文用「」，英文用 "" |
| 省略号 | 用 `…`（单个字符），不用 `...` |

### 5.4 数字

所有数字统一开等宽：

```css
.a-tnum { font-variant-numeric: tabular-nums; }
```

必须开启的场景：

- 列表右侧统计（浏览 / 回复）
- 表格数字列
- 分页页码与「1–20 / 1,284」
- 侧栏统计
- 时间戳（B 方向尤其明显，A 也要求）
- 价格、积分、等级

**千分位**：≥1000 用逗号（`1,284`）；≥10000 在列表里缩写为 `1.2k`，详情页仍显示全量。

### 5.5 日期与时间

| 场景 | 格式 | 示例 |
|---|---|---|
| 列表项相对时间 | `2H` / `1D` / `3D` | 与等宽字体配合，大写 |
| 列表项完整日期 | `10-20` | 同年省略年份 |
| 详情页时间 | `2026-10-20 08:42` | 完整 |
| 公告日期 | `10-18` | 侧栏空间有限 |

**禁止**：`2小时前`、`昨天 08:42`、`2026年10月20日` 混用。同一页只用一种格式。

### 5.6 避头尾（简版）

中文标点不能出现在行首。CSS 处理：

```css
.a-content p { line-break: strict; overflow-wrap: anywhere; }
```

长英文单词、URL、代码用 `overflow-wrap: anywhere` 强制断行，避免撑破容器。

## 六、标题与正文的搭配

### 6.1 层级对比表

同一屏出现两级标题时，字号差至少 **1.4 倍**：

| 上级 | 下级 | 比值 | 是否够 |
|---|---|---|---|
| 56 | 22 | 2.5× | ✅ |
| 40 | 22 | 1.8× | ✅ |
| 28 | 18 | 1.55× | ✅ |
| 22 | 16 | 1.37× | ⚠️ 临界，需靠字重（600 vs 400）与颜色（ink vs ink-2）补足 |
| 18 | 14 | 1.28× | ❌ 不够，必须换用其他手段（大写标记、下划线） |

### 6.2 三级信息结构（列表项为例）

```
标题     22px / 600 / ink        ← 第一层
摘要     16px / 400 / ink-2      ← 第二层
元信息   12px / 400 / ink-2      ← 第三层（靠字号掉 4px 且切到等宽）
类型标记 11px / 600 / ink-2 / 大写 + 0.14em + 下划线  ← 前置信号
```

**不允许**用彩色区分层级（除橙红的「当前位置」）。

## 七、正误对照

| ❌ 错 | ✅ 对 | 原因 |
|---|---|---|
| 标题 `font-size: 20px` | `22px` | 20 不在 9 档 |
| 正文 `line-height: 1.5` | `1.7` | 中文长文 1.5 太挤 |
| 中文标题 `letter-spacing: 0.05em` | `-0.02em` | 中文放大字距显松散 |
| 元信息 `#9B9B9B` | `#6B6B6B` | #9B9B9B 对比度 2.8 不达标 |
| 统计数字 `font-weight: 400` | `tabular-nums` + 600 | 数字不对齐会跳 |
| 按钮 `rgba(255,59,0,.9)` | `#FF3B00` | 不做透明度变体 |
| 标题 `font-weight: 800` | `700` | 中文 800 会糊 |
| 日期 `2026年10月20日` | `2026-10-20` | 中文日期占宽且不齐 |
