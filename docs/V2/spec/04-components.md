## 一、按钮

### 1.1 三尺寸

| 尺寸 | 类名 | 高 | 左右内边距 | 字号 | 字重 | 用途 |
|---|---|---|---|---|---|---|
| 大 | `.a-btn` | 40 | 20 | 14 | 600 | 表单提交、页面主操作 |
| 中 | `.a-btn.sm` | 32 | 14 | 12 | 600 | 行内操作、卡片按钮 |
| 文字 | `.a-btn.text` | auto | 0 | 14 | 600 | 次级操作、表格内操作 |

**没有 26 / 28 / 34 / 36 等中间高度。**

### 1.2 五种变体

| 变体 | 类名 | 底 | 字 | 边 | 用途 |
|---|---|---|---|---|---|
| 主 | `.a-btn` | `--a-ink` | `--a-bg` | `--a-ink` | 默认主操作（黑实底） |
| 强调 | `.a-btn.accent` | `--a-accent` | `--a-accent-ink` | `--a-accent` | 全页唯一最重要的操作（≤1/页） |
| 描边 | `.a-btn.ghost` | 透明 | `--a-ink` | `--a-line` | 次要操作 |
| 文字 | `.a-btn.text` | 透明 | `--a-ink` | 无（下划线 1px） | 三级操作 |
| 危险 | `.a-btn.danger` | 透明 | `--a-ink` + 删除线 | `--a-ink` | 删除、封禁、举报 |

### 1.3 状态

| 状态 | 变化 |
|---|---|
| hover（黑实底） | 底变透明，字变 `--a-ink`，边保持 |
| hover（强调） | 底变透明，字变 `--a-accent` |
| hover（描边） | 边变 `--a-ink` |
| hover（文字） | 下划线加粗到 2px |
| hover（危险） | 删除线保持，字重 700 |
| active | `transform: translateY(1px)`（**唯一允许的位移**，1px） |
| focus-visible | `outline: 2px solid var(--a-accent); outline-offset: 2px` |
| disabled | 底 `--a-line`，字 `--a-ink-4`，边 `--a-line`，`cursor: not-allowed`，无 hover |
| loading | 文字换成「处理中…」，宽度不变，`pointer-events: none` |

### 1.4 结构

```html
<button class="a-btn">发布话题</button>
<button class="a-btn accent">立即注册</button>
<button class="a-btn ghost">取消</button>
<button class="a-btn text">查看更多</button>
<button class="a-btn danger sm">删除</button>
```

### 1.5 图标按钮

| 尺寸 | 类名 | 尺寸 | 图标 |
|---|---|---|---|
| 标准 | `.a-icon-btn` | 32×32 | 16 |
| 小 | `.a-icon-btn.sm` | 26×26 | 14 |

必须带 `title` 或 `aria-label`。图标与按钮边距 8。

## 三、标签与标记

### 3.1 内容类型标记（A 的核心识别）

```html
<span class="a-type">QA</span>
```

| 项 | 值 |
|---|---|
| 字号 | 11 |
| 字重 | 600 |
| 字距 | 0.14em |
| 大小写 | 全大写 |
| 颜色 | `--a-ink-2` |
| 装饰 | 底边 1px `--a-ink-4`，`padding-bottom: 1px` |
| 下方间距 | 10 |

**四种类型的文案**：

| 类型 | 文案 |
|---|---|
| 话题 | `TOPIC` |
| 动态 | `MOMENT` |
| 问答 | `QA` |
| 文章 | `ARTICLE` |

**不用颜色区分类型**。色弱用户靠文字即可分辨。

### 3.2 标签（Tag）

| 选中 | 边框 `--a-ink`，字 `--a-ink`，字重 600 |
| hover | 边框 `--a-ink-4` |

### 3.3 分类 chip（筛选条）

| 项 | 值 |
|---|---|
| 高度 | 26 |
| 内边距 | `0 11` |
| 字号 | 12 |
| 选中 | 底 `--a-ink`，字 `--a-bg` |
| 未选中 | 透明底，字 `--a-ink-2` |

### 3.4 角标

| 类型 | 规格 |
|---|---|
| 未读数字 | 最小 15×15，`padding: 0 3`，字号 9，等宽，底 `--a-accent`，字白，圆角 999 |

**超过 99 显示 `99+`；归零后整个角标消失，不显示 0。**

  </div>

    <div class="a-author"><span class="a-dot">LY</span>林一</div>

| 摘要 | 16 / 400 / 1.7 / `--a-ink-2`，2 行截断 |

### 4.3 空态

```html
<div class="a-empty">
  <div class="a-empty-mark">—</div>
  <div>
    <h3>这里还没有内容</h3>
    <p>成为第一个发布的人，一条清晰的开场会带来更多回复。</p>
  </div>
  <button class="a-btn sm">发布第一条</button>
</div>
```

| 项 | 值 |
|---|---|
| 容器 | `border: 1px var(--a-line)`，内边距 `64 32`（上下 / 左右） |
| 栅格 | `60px minmax(0,1fr) auto`，gap 24 |
| 标记 | `—` 28px 等宽，`--a-ink-4` |
| 标题 | 14 / 600 |
| 说明 | 12 / `--a-ink-2` |
| 动作 | 一个中号按钮 |

**空态必须有一个可点的下一步。** 没有「仅文字」的空态。
