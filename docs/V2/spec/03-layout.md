## 一、网格

### 1.1 12 栏基础网格

```css
.a-grid {
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  gap: var(--a-gap);          /* 24px */
}
```

| 项 | 值 |
|---|---|
| 栏数 | 12 |
| 栏距 | 24 |
| 容器 | 1200 |
| 单栏宽 | `(1200 - 48 - 11×24) / 12 ≈ 74px` |
| 最小宽度 | 用 `minmax(0, 1fr)`，禁止 `1fr`（内容会撑破） |

**为什么是 12**：能整除 2 / 3 / 4 / 6，8 栏内容 + 4 栏侧栏、6+6、4+4+4、9+3 都能落格。

### 1.2 常用跨栏

| 布局 | 跨栏 | 用途 |
|---|---|---|
| 8 + 4 | 内容 + 侧栏 | 列表页 |
| 4 + 4 + 4 | 三等分 | 统计卡、模块入口 |
| 6 + 6 | 两等分 | 对比区、双列列表 |
| 9 + 3 | 内容 + 窄栏 | 详情页 + 目录 |
| 12 | 通栏 | 页头、表格、页脚 |

### 1.3 非网格场景

两栏页面（列表 + 侧栏）**不用 12 栏**，直接用：

```css
grid-template-columns: minmax(0, 1fr) var(--a-side);   /* 280px */
gap: var(--a-sp-6);                                     /* 32px */
```

理由：侧栏固定 280，主区自适应，比「8 栏 + 4 栏」更稳（4 栏在 1200 容器里是 392px，太宽）。

## 二、容器

| Token | 值 | 用在哪 |
|---|---|---|
| `--a-w` | `1200px` | 前台全部页面 |
| `--a-w-admin` | `1440px` | 后台 `/dashboard/*` |
| `--a-reading` | `760px` | 详情页正文 |
| `--a-form` | `760px` | 发布页、设置页 |
| `--a-side` | `280px` | 右侧栏 |

### 2.1 容器写法

```css
.a-wrap {
  width: 100%;
  max-width: var(--a-w);
  margin: 0 auto;
  padding: 0 var(--a-sp-5);    /* 24 */
}
```

**所有页面必须包在 `.a-wrap` 里**，不允许出现未封顶宽度的内容区（除后台表格横向滚动区）。

## 三、断点（4 档）

| 档 | 范围 | 容器 | 页面留白（上/左右/下） | 分栏 | 顶栏 |
|---|---|---|---|---|---|
| **L** | ≥ 1200 | 1200 | 64 / 24 / 96 | 内容 + 280 侧栏 | 完整（logo + 导航 + 搜索 + 头像） |
| **M** | 900 – 1199 | 100% | 48 / 20 / 64 | 侧栏下沉到内容下方 | 完整 |
| **S** | 640 – 899 | 100% | 32 / 16 / 48 | 单栏 | 折叠：隐藏导航，留 logo + 搜索图标 + 头像 |
| **XS** | < 640 | 100% | 24 / 16 / 40 | 单栏，列表项元信息并入第二行 | 折叠：只留 logo + 汉堡 + 头像 |

```css
/* L 默认 */
@media (max-width: 1199px) { /* M */ }
@media (max-width: 899px)  { /* S */ }
@media (max-width: 639px)  { /* XS */ }
```

**只有这 4 档，不做逐像素适配。**

## 四、五类页面骨架

### 4.1 列表页（首页 / 话题 / 文章 / 分类 / 标签）

```
┌──────────────────────────────────────────────┐
│ 顶栏 64                                       │
├──────────────────────────────────────────────┤
│ 筛选条 52（分类 + 计数）                        │
├──────────────────────────────────────────────┤
│ 页头：kicker 11 + 标题 56 + 说明 14 + 右侧统计   │  ← 底 2px 硬线
├──────────────────────────────────────────────┤
│ ┌───────────────────────────┐ ┌────────────┐ │
│ │ 列表头部（Latest / 排序）   │ │ 站点概况    │ │
│ │ ─────────────────────────  │ │ ──────────  │ │
│ │ 列表项 ×N                  │ │ 活跃成员    │ │
│ │ ─────────────────────────  │ │ ──────────  │ │
│ │ 空态（如无内容）            │ │ 最新公告    │ │
│ │ ─────────────────────────  │ │            │ │
│ │ 分页                       │ │            │ │
│ └───────────────────────────┘ └────────────┘ │
│        minmax(0,1fr)              280        │
├──────────────────────────────────────────────┤
│ 页脚                                           │
└──────────────────────────────────────────────┘
```

- 列表项内边距 `24px 0`，用 1px 线分隔
- 列表项三栏：`60px  |  1fr  |  240px`，gap 24
- 侧栏 `position: sticky; top: calc(顶栏高 + 24px)`

### 4.2 详情页（话题 / 文章）

```
┌──────────────────────────────────────────────┐
│ 顶栏 64                                       │
├──────────────────────────────────────────────┤
│ 面包屑 12（数学 / 函数 / 正文）                  │
├──────────────────────────────────────────────┤
│ ┌─────────────────────────┐ ┌──────────────┐ │
│ │ 类型标记 11               │ │ 目录（sticky）│ │
│ │ 标题 40 / 1.15           │ │ ────────────  │ │
│ │ 作者行 12（头像24+名+时间）│ │ 本文目录      │ │
│ │ ─────── 2px 硬线 ─────── │ │              │ │
│ │ 正文 16 / 1.7            │ │ 作者卡        │ │
│ │   版心 760               │ │              │ │
│ │ ─────── 1px 线 ───────── │ │ 相关推荐      │ │
│ │ 操作条（赞/收藏/分享）     │ │              │ │
│ │ ─────── 2px 硬线 ─────── │ │              │ │
│ │ 评论区                   │ │              │ │
│ └─────────────────────────┘ └──────────────┘ │
│        760（正文）              280           │
└──────────────────────────────────────────────┘
```

- 正文区 `max-width: var(--a-reading)`（760）
- 标题宽度不锁，可略宽于正文，但不超过容器 2/3
- 目录侧栏可选；无目录时正文居中

### 4.3 发布页

```
┌──────────────────────────────────────────────┐
│ 顶栏 64                                       │
├──────────────────────────────────────────────┤
│         ┌────────────────────────────┐       │
│         │ 标题输入 28 / 无边框 / 底 1px │       │
│         │ ─────────────────────────── │       │
│         │ 分类 chip 26 + 标签 chip      │       │
│         │ ─────────────────────────── │       │
│         │ ┌ 编辑器 ─────────────────┐ │       │
│         │ │ 工具栏 40（浅灰底）      │ │       │
│         │ ├─────────────────────────┤ │       │
│         │ │ 正文区 min-h 320        │ │       │
│         │ │ 16 / 1.7                │ │       │
│         │ └─────────────────────────┘ │       │
```

```
│ 内容      │ 页头：标题 28 + 右侧主操作          │
│ 社区      ├───────────────────────────────────┤
```

## 五、垂直节奏

| 位置 | 间距 |
|---|---|
| 顶栏 → 筛选条 | 0（筛选条自带 52 高） |
| 筛选条 → 页头 | 64 |
| 页头 → 内容区 | 32 |
| 区块之间 | 48 |
| 列表项上下内边距 | 24 |
| 列表 → 空态 | 32 |
| 列表 → 分页 | 24 |
| 内容 → 页脚 | 96 |
| 页脚内部 | 上下 48 |

页面从上到下的节奏：

```
64  页面顶部
 ↓
[页头：kicker 11 → 标题 56 → 说明 14 → 右侧统计]
32  页头下
 ↓
[筛选条 52]
24
 ↓
[列表项 ×N，每项 24 上下]
24
 ↓
[分页]
96  页面底部
```

## 六、侧栏规则

| 项 | 规则 |
|---|---|
| 宽度 | 固定 280 |
| 主区与侧栏 gap | 32 |
| 定位 | `position: sticky; top: calc(顶栏 64 + 24)` |
| 内部模块间距 | 48 |
| 模块标题 | 11px 大写 + 0.14em + 底 2px 黑线 |
| M 档（900-1199） | 下沉到内容下方，改 `grid-template-columns: repeat(3, 1fr)` |
| S / XS 档 | 下沉后单列 |

**侧栏永不隐藏**，只下沉。信息不因屏幕窄而消失。

## 七、列表项结构（核心组件）

```
┌──────┬───────────────────────────────┬──────────────┐
│ 01   │ QA                            │ 林一          │
│ 60   │ 二次函数图像怎么快速判断开口方向 │ ──────────── │
│      │ 老师上课讲的是看 a 的正负，但…   │ 128 VIEW     │
│      │                               │ 24 REPLY     │
│      │                               │ 2H           │
└──────┴───────────────────────────────┴──────────────┘
  60             minmax(0,1fr)                240
```

| 格 | 宽度 | 内容 |
|---|---|---|
| 序号 | 60 | 等宽 28px，`--a-ink-4`，hover 变 `--a-accent` |
| 内容 | 自适应 | 类型 11 → 标题 22 → 摘要 16（2 行截断） |
| 元信息 | 240 | 作者行 + 统计（等宽 12） |

M / S 档：序号缩到 44；XS 档：元信息跨列到第二行，横向排列。

## 八、禁止

- ❌ 出现 `calc(100% - 260px - 10px)` 这类手算宽度（用 grid）
- ❌ 侧栏用 `display: none` 隐藏
- ❌ 内容区超过 1200（前台）
- ❌ 表格不封顶高度就加 `sticky` 表头（不生效）
- ❌ 用背景色块分区（只用线）
- ❌ 页面左右留白小于 16
