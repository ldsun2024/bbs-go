# 01 · Design Tokens

> 方向：**A · 瑞士网格（Swiss Grid）**
> 版本：v1.0 ｜ 2026-10-20
> 唯一来源：本文件定义的所有变量与 `assets/tokens.css` 完全一致。**任何页面不得写出表中未列的值。**

---

## 一、设计约束（先看这四条，再看表）

1. **零圆角、零模糊阴影** —— 全站 `border-radius: 0`；浮层用「2px 硬边 + 硬偏移阴影」，不用高斯模糊。
2. **一个强调色** —— 橙红只用于「可交互」与「当前位置」，全页出现次数 ≤ 6。
3. **危险不用红色** —— 危险操作靠**字重 + 删除线 + 二次确认**表达，色值用纯黑。避免与橙红抢信号。
4. **线是唯一的分隔手段** —— 不用背景色块分区，只用 1px / 2px 硬线。

## 二、颜色

### 2.1 基础色

| Token | 值 | 用途 | 对比度（on `--a-bg`） |
|---|---|---|---|
| `--a-bg` | `#FFFFFF` | 页面底色、卡片底、输入框底 | — |
| `--a-ink` | `#111111` | 正文、标题、主要图标、硬线 | **18.1:1** ✅ |
| `--a-ink-2` | `#6B6B6B` | 次要文字、摘要、说明、元信息 | **5.3:1** ✅ |
| `--a-ink-3` | `#9B9B9B` | 占位符、弱化标签、大写小字 | 2.8:1 ⚠️ **仅限 ≥11px 且非关键信息** |
| `--a-ink-4` | `#C9C9C9` | 序号、禁用态、分隔装饰 | 装饰用，不可承载文字语义 |
| `--a-surface-hover` | `#FAFAFA` | 列表行 / 表格行 hover 底、工具栏底、禁用输入底 | — |
| `--a-skeleton` | `#F2F2F2` | 骨架块底色 | — |
| `--a-line` | `#E3E3E3` | 普通分隔线、卡片边、输入框边 | — |
| `--a-line-hard` | `#111111` | 页头下沿、区块顶线、强调分隔 | — |

> ⚠️ `--a-ink-3` 与 `--a-ink-4` **不能**用于正文、说明、按钮文字。需要「更弱的文字」时用 `--a-ink-2`。

### 2.2 强调与语义色

| Token | 值 | 用途 | 对比度 | 使用限制 |
|---|---|---|---|---|
| `--a-accent` | `#FF3B00` | 主按钮、当前导航下划线、列表序号 hover、focus 环、选区 | 3.5:1 | **仅用于 ≥24px 文字或非文字元素**（按钮底、下划线、色块） |
| `--a-accent-ink` | `#FFFFFF` | 橙红底上的文字 | 5.9:1 ✅ | 仅橙红实底 |
| `--a-success` | `#0A7D3F` | 成功提示、已解决、通过 | 4.9:1 ✅ | 可与文字同用 |
| `--a-success-soft` | `#EAF4EE` | 成功提示底 | — | 需搭配 `--a-success` 文字 |
| `--a-warning` | `#B37400` | 警告、待审核、未解决 | 3.9:1 | **仅 ≥16px 或 600 字重** |
| `--a-warning-soft` | `#FDF4E3` | 警告提示底 | — | 需搭配 `--a-warning` 文字 |
| `--a-danger` | `#0A0A0A` | 危险操作文字、错误文案 | 18.6:1 ✅ | 必须同时加 `text-decoration: line-through` 或 2px 下划线 |
| `--a-danger-soft` | `#F5F0F0` | 危险区域底（如删除确认） | — | 面积不超过 1/3 屏 |
| `--a-mask` | `rgba(17,17,17,.55)` | 弹窗遮罩 | — | 固定值，不做透明度变体 |

> **为什么危险色是黑的**：橙红已独占「可交互」信号，再引入红色会让用户分不清「能点」与「危险」。瑞士平面设计的做法是：危险靠**删除线**（`line-through`）与**字重 700** 表达，色值不参与。

### 2.3 语义使用矩阵

| 场景 | 用色 |
|---|---|
| 主按钮 | 底 `--a-accent`，字 `--a-accent-ink` |
| 常规按钮 | 底 `--a-ink`，字 `--a-bg` |
| 描边按钮 | 底透明，边 `--a-line`，字 `--a-ink` |
| 文字按钮 | 无底无边，字 `--a-ink`，下划线 1px |
| 危险按钮 | 底透明，边 `--a-ink`，字 `--a-ink` + `line-through` |
| 当前导航 | 字 `--a-ink` + 底边 2px `--a-accent` |
| 悬停 | 文字 `--a-ink-2` → `--a-ink`；序号 `--a-ink-4` → `--a-accent` |
| 禁用 | 字 `--a-ink-4`，边 `--a-line`，`cursor: not-allowed` |
| 焦点 | `outline: 2px solid var(--a-accent); outline-offset: 2px` |

|---|---|---|---|---|---|

| `--a-fs-h3` | `22px` | 1.35 | 600 | `-0.01em` | 列表项标题 |
| `--a-fs-h4` | `18px` | 1.5 | 600 | `0` | 小标题、卡片标题、侧栏标题 |
| `--a-fs-body` | `16px` | 1.7 | 400 | `0` | 正文、摘要 |
| `--a-fs-ui` | `14px` | 1.6 | 400 | `0` | 按钮、导航、表单控件、次要正文 |

### 唯一例外：`--a-fs-error`

| Token | 值 | 用途 | 约束 |
|---|---|---|---|
| `--a-fs-error` | `120px` | 错误页的 404 / 500 / 403 编号 | 只允许 `pages/states/error.html` 使用；不作为组件字号，不参与九档 |

除这一处，任何页面、任何组件都只能引用上表九档，不得直接写 px 数值。

## 六、圆角

```css
--a-radius: 0;
```

**全站唯一值：`0`**。按钮、输入框、卡片、标签、头像（方形）、弹窗、图片，一律直角。

唯一的例外是**圆形**：`border-radius: 999px`，仅用于「在线状态点」「未读红点」这类直径 ≤ 8px 的圆点。

---

## 七、阴影

A 方向**不用模糊阴影**，只用硬偏移阴影，模拟纸张叠放。

| Token | 值 | 用途 |
|---|---|---|
| `--a-shadow-none` | `none` | 所有卡片、按钮、输入框 |
| `--a-shadow-pop` | `8px 8px 0 rgba(17,17,17,.08)` | 浮层：弹窗、下拉、Toast |
| `--a-shadow-lift` | `4px 4px 0 rgba(17,17,17,.06)` | 轻浮层：气泡提示、hover 卡片 |

判定标准：**只有脱离文档流的元素才允许有阴影。**

## 八、动效时长

| Token | 值 | 用途 |
|---|---|---|
| `--a-dur-fast` | `120ms` | hover 变色、focus 环、按钮状态 |
| `--a-dur-base` | `180ms` | 入场淡入、展开收起 |
| `--a-dur-slow` | `260ms` | 弹窗进出、抽屉 |
| `--a-ease` | `cubic-bezier(.2,.7,.3,1)` | 全站唯一缓动曲线 |

**禁止**：弹跳、缩放、旋转、超过 300ms 的动画、无限循环动画。

## 十一、自检清单

任何页面交付前跑一遍：

- [ ] 是否出现 `border-radius` 非 0 值（除 999 圆点）
- [ ] 是否出现表中未列的字号（13/15/17/19/20/21/24…）
- [ ] 是否出现表中未列的间距（13/14/18/28/36/40…）
- [ ] 是否出现表中未列的颜色（任何未在 2.1 / 2.2 的 hex）
- [ ] 橙红在单页出现次数是否 ≤ 6
- [ ] 危险操作是否用了红色（应该用黑 + 删除线）
- [ ] 是否有高斯模糊阴影（应该有则仅浮层，且为硬偏移）
- [ ] 是否有超过 300ms 的动效
